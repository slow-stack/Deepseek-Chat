# 反馈渠道

这个项目没有后台、没有群聊，也没打算为了收反馈去开一个。三条路都通到同一个地方：

## 1. GitHub 工单（推荐）

[新建工单](https://github.com/slow-stack/Deepseek-Chat/issues/new/choose)

- 能跟进、能看到别人提过什么
- App 内「设置 → 关于 → 反馈」填完直接跳到这里，正文会带好版本与环境信息
- 提之前先搜一下有没有重复的

## 2. 邮件

`work@modusensus.space`

- 不想注册 GitHub 账号就走这条
- App 内同样的入口会打开系统邮件客户端，正文已经写好
- 私人问题、安全问题用这条更合适

## 3. 复制走

App 内「设置 → 关于 → 反馈 → 复制」把正文复制到剪贴板，你爱贴哪贴哪（论坛、私聊、自己的笔记）。

## 提之前

- 版本看「设置 → 关于 → 版本」
- 复现步骤比截图有用，截图比「用不了」有用
- **不要贴 API Key、token，或整段私人对话** —— 这是个旁装 App，密钥就是你自己的钱包
